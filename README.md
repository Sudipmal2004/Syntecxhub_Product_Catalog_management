# Product Catalog Management System

This is a full-stack web development project built to manage products easily. Users can view, search, filter, add, edit, and delete products.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* MongoDB
* Mongoose

## Features

* View all products
* Search products by name or category
* Filter and sort products
* Add new products
* Edit and delete products
* User registration and login
* Dashboard with product statistics
* Responsive design for different devices

## Installation

**1. Install the dependencies**

```bash
npm install
```

**2. Configure the environment**

Create a `.env` file in the project folder and add your MongoDB connection details and JWT secret.

**3. Start the application**

```bash
npm start
```

## Run the Project

After starting the server, open your browser and visit:

http://localhost:3000

## Project Status

The project runs locally, and the server connects to MongoDB successfully.
